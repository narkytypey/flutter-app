Run 2026-10-06 against `screens.html` with all 30 blocks in it (`1b 2b 2a 2c
2d 3a 4a 5c 6c 8b`, then `9b 9c 6b 6a 7c 10a 10b 10d 10e 3c 5a 5b 8a 8c 7b

so text was measured in the real faces.

## What the runs (and looking) found, and what changed

The checker only measures spill past the phone frame and clipped leaf text,
so each fix below was also looked at in a clipped screenshot with the Read
tool (`1b`, `2a`, `2b`, `2c`, `2d`, `3a`, `4a`, `4c`, `5b`, `5c`, `6c`, `7b`,
`7c`, `8b`, `8c`, `9b`, `10e`, `3c`, `1a`, `1c` at 1.0; `1b`, `2b`, `8b` at
320 × 2.0; `6c` at 390 × 2.0; `3a` at 320 × 1.3).

1. **Hosts in ellipsized meta lines spilled** (`1b`, `6c` at 320 × 2.0:
   `notes.example.org` 26 px, `forum.example.com` 29 px). A Mono span inside
   an ellipsized Sans line keeps its full width. Meta and subtitle lines that
   carry a host now **wrap** (`overflow-wrap: anywhere`) instead of
   ellipsizing, so rows grow — which is also the direction's rule (the host is
   the fact you check; it is never cut). Names still ellipsize.
2. **The pill host was cut to "foru…"** at 320 × 2.0. It now wraps too, and
   the pill's radius is 24 px instead of "full" so a three-line pill stays a
   rounded rectangle, not a circle. At 390 × 1.0 the host `forum.example.com`
   fits whole on one line beside its `SOCKS5` badge (the pill's paddings and
   gaps were tightened to make that true; every icon target is still 48 dp).
3. **`3 OPEN` broke over two lines** at 320 × 2.0. The pill is `nowrap` with
   12 dp side padding; it fits beside three 48 dp icons.
4. **`6c` value overlapped its label at 390 × 2.0** (`127.0.0.1:9050` has no
   break opportunity and ran left over "Proxy"; the checker cannot see an
   overlap inside the frame). Rows now `flex-wrap`: the value drops under its
   label, right-aligned, when both do not fit, and the chevron is kept with
   the value.
5. **`1c` "Marketplace" spilled 39 px** from a saved tile at 320 × 2.0 (the
   tile's column was `align-items: flex-start`, so the ellipsized name was
   unconstrained). Tiles now stretch their children.
6. **The step bar's unfinished segments were 1.72:1** (raised on ink) — the
   only way to see that there are three steps. They are now a 1.5 dp `--edge`
   outline, 5.76:1.
7. **The chip remove × was a 28 dp target** (`10e`). It is 48 × 48 dp,
   overlapping the chip's own 48 dp row with negative margins.

## Numbers

- **Smallest text:** 12 px × scale (`--fs-caption`): badges (`SOCKS5`,
  `Wipes on exit`, `Proxy`/`Temp`/`Lock`), the dashboard tab labels, the
  file-kind and script-kind badges (`PDF`, `CSS`, `JS`). Hosts inside meta
  lines are 13 × 0.97 ≈ 12.6 px. Every text size scales with `?scale=`;
  monogram letters scale too but are capped (20 px in a 44 dp tile), as the
  app's `Monogram` scales letters down to fit.
- **Smallest touch target:** 48 × 48 dp — every icon button (pill reload and
  shield, panic, back/forward/menu, form ×/back, `2c` row ×, chip ×, `Aa`
  and the reader theme icon), text buttons (`Save`, `Edit`), workspace chips
  (48 dp tall, 36 dp visual), marker swatches. Keypad keys are 64 dp tall
  (56 dp when the phone is under 640 dp, i.e. `w=320`). Rows are 56–72 dp and
  are the target for their switch or radio. Inert header icons on `8b`/`8c`
  are drawn without a target (text-3, `aria-hidden`), as built.
- **Pairings below 4.5:1 (text) or 3:1 (marks): none.** The table in
  `TOKENS.md` covers the system; the mockups introduced 19 further pairings,
  now appended to `contrast-pairs.txt` under "added 2026-10-06" and measured
  with `tools/contrast.py --table`: all pass. Lowest new text pair: JS badge
  amber on raised 5.59:1; lowest new mark: the background-open light (`--edge`)
  on the sheet, 4.18:1. Lowest text anywhere stays `7b`'s `Remove site`,
  danger on raised, 4.54:1. The page placeholders behind chrome (`#1A1816`,
  `#2A2724`, `#322F2B`) carry no meaning and no text.

## Copy check

Every text node inside every phone was compared against the two inventory
files and the canvas file (a Playwright script walking the DOM). The only
node not found verbatim is `104`, `6c`'s illustrative Trackers count (data,
labelled as illustrative in that block's tag, as are `52`, `8` and the
`Location · Allowed` row). Case changes are CSS only (`.sc`), so text nodes
keep the inventory's capitals.

## Additions made while building the screens (not in TOKENS.md)

- **Background-open light:** a solid `--edge` dot for a container that is
  open but not viewed (`2c`), between the jade *viewed* light and the hollow
  *idle* ring. Measured 4.18:1 on the sheet.
- **Inert-but-on switch:** dashed `--text-3` outline with a `--text-3` knob
  and check (`2d`'s Decoy vault and Hide from app switcher, built as on and
  inert), 6.29:1 on the group.
- **`10e`'s add chip** is dashed, as the canvas draws it (the code is solid;
  unreconciled in the inventory).
- **`8a`** shows every step pending, as built (`openStepsFor`), with the load
  line in text-2 at 60 %, not jade.
