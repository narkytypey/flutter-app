Restyle v2 — three directions

Overnight, three visual directions for Container were designed from the same research and audit: A — Daylight, B — Instrument and C — Rooms. Each has a brief, measured tokens, a logo and app icon, and every screen block redrawn as an HTML mockup. Four critics (threat model, accessibility, implementation cost, familiarity) and the three advocates then debated them over two rounds. This page summarises the result: the recommendation, what still needs your decision, and each direction side by side.

Recommended  B — Instrument, revised

Dark only; warm near-black; IBM Plex Sans for words and Plex Mono for values; four surfaces; every text tone AA; jade kept as the one live colour and taken off switches, checks, tabs and step bars; 48 dp targets; a host that is never cut. Seven elements are folded in from A and C: a 13 sp floor, a check on every selected chip, the risky 8b choice as a text button, the host in Plex Sans 16/500 and never ellipsized, segments selected by outline plus check, throwaway and Tor told apart by the pill’s case shape, and 24 dp between “Close all and wipe” and panic. It is the only direction no lens blocks, and the cheapest (7–9 agent-days).

Decisions waiting for you

The build can proceed on the assumption in each item; each is reversible.

  1. Dark only, or a light variant later? Assumed dark only. A light variant over B’s roles costs about 1.5–2 agent-days plus a second token table, and leaves WebView’s dark-page seam.
  2. Sentence case for labels? Needs an explicit exception to “never re-capitalise” and moves ~99 test finders. Assumed no: labels keep their stored caps.
  3. Layout rulings a restyle shouldn’t take 6c leading with protection instead of Proxy; panic out of 2b’s top-right corner; ☰ → ⋮; Tor before SOCKS5 in 2a. Assumed canvas order.
  4. A visible word for wipe-on-exit / throwaway in the pill Assumed shape (dashed case) plus a screen-reader label only; no new copy.
  5. 10c / 10a storage sizes Dormant today (fake returns 0), but a real byte count could tell a decoy apart. Recommend a threat-model ruling first. Assumed no change.
  6. 6a’s jade on “Keep blocked” The canvas draws it there; the code had it on “Allow once” with no ruling. Colour only. Confirm.

The three directions

A — Daylight

A browser a Chrome user already trusts: follows the system light/dark setting, Chrome’s grammar and sizes (56 dp bar, 40 dp pill, 48 dp targets, 16 sp body), Atkinson Hyperlegible Next, grouped rounded surfaces; privacy machinery present but quiet.

Recommended

C — Rooms

Make isolation visible: every site is a coloured room whose colour frames the browser chrome while you are inside it; a throwaway, uncoloured, looks different. Warm paper and ink, Figtree large and round, tinted cards instead of hairlines. Breaks “jade = the one colour” on purpose.
